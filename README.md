# Datenschutzinformation zur Videoüberwachung

Dieses Repository enthält die öffentliche Datenschutzinformation zur Videoüberwachung eines privaten Grundstücks gemäß Art. 13 Datenschutz-Grundverordnung (DSGVO).

Die Website wird über **GitHub Pages** veröffentlicht und ist über den auf dem Hinweisschild angebrachten QR-Code erreichbar.

---

## Projektziel

Ziel des Projekts ist es,

- Besucher transparent über die Videoüberwachung zu informieren,
- die gesetzlichen Informationspflichten nach Art. 13 DSGVO zu erfüllen,
- eine dauerhaft erreichbare Informationsseite bereitzustellen,
- und dabei vollständig auf Cookies, Tracking und Werbung zu verzichten.

---


---

## Verwendete Technik

- HTML5
- CSS3
- GitHub Pages

Es werden bewusst **keine** externen Bibliotheken oder Frameworks verwendet.

Die Website nutzt

- keine Cookies,
- kein Tracking,
- kein JavaScript,
- keine externen Schriftarten,
- keine externen Dienste.

---

## Datenschutz

Die Website dient ausschließlich der Bereitstellung von Informationen nach Art. 13 DSGVO.

Sie verarbeitet selbst keine personenbezogenen Daten.

---

## Pflege

Änderungen erfolgen ausschließlich durch die Verantwortlichen.

Bei Änderungen der Videoüberwachung oder der rechtlichen Rahmenbedingungen wird diese Website entsprechend aktualisiert.
